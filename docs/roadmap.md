# Roadmap

## Next

- A Spanish podcast: the podcast code is tied to one German feed, so the
  Spanish pack sets `media.podcast: false`.
- A pack without a video channel (`media.video_channel: null`): the dashboard
  and the daily plan assume a channel today.
- Dictionary-based Spanish capture: gender, plural and part of speech for a
  captured word, so a noun arrives with its article.
- Merging the German, Dutch and Spanish capture pipelines.

## Later ideas

- Better cloze-deletion cards.
- Optional daily review limits.
- A better scheduler (FSRS-like).
- More browse filters and bulk card actions.
- Better form styling and validation messages.
- AI-assisted card generation from pasted text.
- Deck sharing between users.
- Email-based password reset.
- Media and audio on cards.
- Anki import and export.
- Dark mode.
- Off-site backups: built, off until a destination is configured
  ([backups.md](backups.md)).
