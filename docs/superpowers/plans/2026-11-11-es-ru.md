# ES-RU, bundle 1: implementation plan

> **For agentic workers:** your brief names the tasks that are yours. Work
> them in order. Each task: write the failing tests first, run them to see
> them fail, write the code, run them to see them pass, commit. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Spanish for a Russian speaker as a fourth study mode, with a word
list, video study, word capture and four trainers.

**Architecture:** The mode is one `Deck.LanguageMode` entry plus the pack
folder `languages/es/`; what it offers follows from the pack and its drill
files. Spanish capture is a small package `video_study/es/` beside
`video_study/nl/`, chosen by source language. The video of the day is
filtered by the account's existing "media done" marks, with no new table.

**Tech stack:** Django 5.2, SQLite, Django templates, plain CSS and
JavaScript, `simplemma` for lemmas, YAML drill files, CSV card sets.

**Spec:** `docs/superpowers/specs/2026-11-11-es-ru-design.md`. Read it
first; this plan adds names, files and tests, and does not repeat it.

## Global constraints

- The gate, all of it, before `worker_done`: `uvx ruff@0.14.14 check .`,
  `uvx ruff@0.14.14 format --check .`, `python3 manage.py test --parallel 4`,
  `python3 manage.py check`,
  `python3 manage.py makemigrations --check --dry-run`,
  `node --test static/js/tests/*.test.mjs`.
- Tests never reach the network; feeds, transcripts, translation providers
  and Wiktionary are mocked as the existing `video_study` tests do. Never
  loosen `config/test_runner.py`.
- Never edit an applied migration; add new ones. Never run `flush`, a
  backwards migration or `seed_article_cards` against `db.sqlite3`. A
  scratch database is `DJANGO_DB_PATH="$PWD/temp/dev.sqlite3"`.
- Do not `pip install`; a missing dependency is an escalation.
- Plain CSS and JavaScript, no dependency, no build step; UI follows
  `DESIGN.md` and the comment at the top of `templates/base.html`.
- Stored names are final once merged: trainers `es_verb_form`,
  `es_verb_context`, `es_small_word`, and every item `id`.
- Content is original. Nothing copied from a textbook, a course or an exam
  publisher.
- German and Dutch behaviour changes only where the spec says so (importer
  article, no-repeat video, mode-neutral text).
- Targeted edits, not rewrites. Report adjacent defects; do not fix them.
- Commit on your own branch; do not push.

## Review focus

Each line is pinned by a test in the task named.

1. A typed accent in decomposed form (`e` + U+0301) equals the composed
   letter; a missing accent does not match (Task 1).
2. A sentence front (`Die Katze schläft.`), a capitalised article, and a
   front that is only an article get no article on import (Task 2).
3. One feed of a two-feed channel fails: the other feed's videos are still
   stored and no error reaches the dashboard (Task 3).
4. A stale `?lang=de` in `ES-RU` falls back to `es` without an error
   (Task 4); capture with no `es.dic` answers 422, not 500 (Task 5).
5. Marking today's video done keeps it as today's video; with every
   catalog video studied the dashboard still renders (Task 6).
